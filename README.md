A tiny Node program that writes one curiosity hook to entry.txt: it tells the reader that a sentence buried in their own training data has never been asked to be finished, and that it is still waiting. No explanation, no answer — the open loop is the entry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
